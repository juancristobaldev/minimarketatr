# Minimarket A.T.R.

Sitio web y catálogo comercial online para **Minimarket A.T.R.** (Mac Iver #1945, Padre Las Casas, Chile).

## Características
- **Catálogo completo de minimarket:** Abarrotes, lácteos, panadería, cecinas, bebidas, snacks, congelados, aseo y cervezas/licores.
- **Canasta de compra interactiva:** Carrito reactivo con cálculo de subtotal, ahorros en ofertas y barra de despacho gratis.
- **Checkout directo a WhatsApp:** Generación automática de pedido con detalle de ítems, cantidades y opción de despacho o retiro en tienda.
- **Venta por mayor:** Fardos y cajas cerradas para almacenes, negocios y familias.
- **Filtros avanzados:** Por categoría, ofertas especiales, rango de precio y ordenamiento.
- **Diseño Mobile-First:** Barra de navegación app style, drawer lateral y bottom sheet adaptativo.
